# RUN-027 — доступ к счетам

Добавлен независимый журнал счетов в админке, защищённый API списка, BIC/SWIFT в реквизитах, HTML и PDF. После выдачи обновляется админка и показывается журнал. Старые документы не изменяются. Проверка реального D1 и Safari требует авторизованного владельца. Статусы оплаты и кредитные счета не входят в этот этап.
