# RUN-045 — синхронизация городов

География волшебства и выбор города при бронировании получают единый список из сохранённого тарифа public-config.fares.km. Добавление и удаление города отражается после загрузки страницы, без отдельной публикации контента. Исходные статические названия скрываются, но DOM сохраняется для прежних ключей редактора. Описание географии не переписывается автоматически, пользовательские тексты и цены не меняются. Предпросмотры используют сохранённые тарифы. Обновлено сообщение админки и версии ресурсов, добавлены тесты. Фактический новый город не проверен в закрытой админке.
