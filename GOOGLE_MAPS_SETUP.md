# Pakkasukko — Google Maps setup

Disabled by default. In a dedicated Google Cloud project enable billing, Maps JavaScript API, Geocoding API and Routes API. Create a JavaScript map ID. Create a browser key with website restrictions for https://pakkasukko.velardream.workers.dev/* and later https://pakkasukko.fi/*, and API restrictions Maps JavaScript API and Geocoding API. Create a separate server key restricted to Routes API; keep it in repository/Worker secrets only. Configure quotas for every enabled API (the Worker also limits route calls globally and per IP). Billing budgets send alerts, not hard spending caps. Check applicable EEA terms and privacy settings before enabling. Add repository secrets PAKKASUKKO_GOOGLE_MAPS_BROWSER_KEY, PAKKASUKKO_GOOGLE_ROUTES_API_KEY, PAKKASUKKO_GOOGLE_MAPS_MAP_ID; never paste keys in issues or chat. The browser key and map ID are intended for public browser use only after activation; server key is never returned. Deploy preview; admin → Карта и автоматический расчёт расстояния → verify settings and enable. Test known city aliases, address search, explicit map click, route estimate, customer submission and owner map link. Disable immediately if errors or unexpected usage. Existing owner-approved city tariffs remain authoritative. Google estimates are not persisted as tariffs. Unknown-city bookings remain subject to agreement. No real Google API calls tested without keys.
