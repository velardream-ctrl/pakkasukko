Kitee — точка выезда. Для автомобиля укажите расстояние в одну сторону, для поезда — общую цену билетов туда и обратно. Изменения действуют для новых заявок.

Оплата бронирования и предоплата по городам

Выберите для каждого города: без предоплаты, полную рассчитанную стоимость поездки, процент от максимальной суммы заказа или фиксированную сумму в евро. Предоплата входит в цену заказа, не прибавляется сверху. Для нового города сначала сохраните тариф дороги.

Выписка авансового счёта и подтверждение фактического поступления денег — отдельные действия в карточке заявки. Время резервируется при выставлении счёта; при неоплате после срока отмените резерв вручную. Условия отмены должны быть разумными: установленного законом штрафа 73,70 € за неявку Деда Мороза нет.

Перед включением проверьте точное банковское имя получателя, финский IBAN и BIC / SWIFT. Без этой галочки сохраняется ручная выдача счёта.

Артисты и длительность выступлений

Задайте стоимость Деда Мороза и дуэта со Снегурочкой для каждой программы и продолжительности. Пустая цена означает, что этот вариант нельзя выбрать. Чтобы предлагать дуэт посетителям, заполните его стоимость и включите переключатель.

Важно: 30-минутные интервалы календаря остаются на месте. Выступление на 45–60 минут можно заказать только внутри открытого интервала не короче этого времени. Для более длинной программы создайте подходящее свободное окно в разделе «Календарь и переезды». Соседние 30-минутные интервалы автоматически не объединяются.

Праздничные тарифы и интервалы времени

Выбирайте даты начала и окончания прямо из раскрывающегося календаря, а часы — из поля времени. Год в календаре нужен только для выбора: сохранённые интервалы повторяются каждый год. При переносе даты начала дата окончания сдвигается вместе с ней. У каждого периода своя надбавка в процентах. Периоды могут переходить через полночь или Новый год. Все часы — по Финляндии. Если интервалы пересекаются, применяется большая надбавка. Изменения действуют только для новых заявок; дорога, гостиница и питание не дорожают.

Включение бронирования

Свободные даты видны посетителям без регистрации. Приём заявок включается отдельно, только после настройки защиты, почтовых уведомлений и информации о персональных данных.
