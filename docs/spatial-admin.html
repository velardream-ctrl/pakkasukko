Обычные фотографии и их кадрирование остаются без изменений. Пространственная фотография повторяет масштаб, положение и обрезку обычного главного фото отдельно на телефоне, планшете и компьютере. Здесь выбираются тип фотографии, способ движения и положение объёмного фона; посетители не увидят переключателей.

При выборе «Наклон устройства» на iPhone может потребоваться один раз коснуться фотографии и разрешить доступ к движению телефона.

Библиотека пространственных сцен

Каждая сцена состоит из прозрачного изображения персонажа и фонового снимка. Во встроенной сцене используется цельная широкая панорама без пустоты за персонажем. Её масштаб, положение церкви и уровень неподвижного снега можно отдельно настроить ползунками для каждого устройства. Для новых сцен снег можно загрузить отдельным слоем.

Добавить новую пространственную фотографию

Для настоящего эффекта сначала нужно подготовить два слоя: персонажа, вырезанного по контуру (PNG с прозрачностью), и восстановленный широкий фон без персонажа. Обычную фотографию можно загрузить отдельно в основном редакторе. Простая загрузка одного фото сама по себе ещё не создаёт объём.

Если отдельный снег не выбран, для двух фоновых слоёв используется один широкий пейзаж, как в нашей тестовой сцене. Максимальный размер одного файла — 32 МБ.

Обычные фотографии

Существующий фотоархив и настройка главного портрета не меняются. Для обычных JPEG, PNG, WebP и изменения кадрирования используй прежний редактор.
