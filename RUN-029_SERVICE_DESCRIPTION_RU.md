# RUN-029 — описание услуги в счёте

Финские и русские наименования автоматически подставляются по типу заказа. В форме подготовки счета их можно отредактировать. Один и тот же текст используется в HTML, тестовом PDF и официальном документе; описание сохраняется в снимке официального счёта. Транспортные расходы выделены отдельно. Налоговый режим, цены и предыдущие записи не меняются. Добавлены проверки текста предпросмотра и сохранения описания.
