# RUN-023 · Размер подписи в шапке

Подпись «Дед Мороз из зимней сказки» по умолчанию подгоняется к ширине надписи PAKKASUKKO без учёта медальона. Бегунок «Размер подписи» задаёт 70–150% этой ширины. При нехватке места увеличение ограничено свободной шириной шапки.

В режиме правок нажмите карандаш у названия. В полном редакторе выберите раздел «Шапка». Настройка хранится в существующей системе черновиков и публикаций.
