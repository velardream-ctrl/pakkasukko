# Pakkasukko — Дед Мороз в Финляндии

Самостоятельный сайт русскоязычного Деда Мороза для детей, семей, утренников и корпоративов. Основные районы: Kitee, Puhos, Tohmajärvi; Joensuu и другие города — по согласованию.

## Изоляция
**Это отдельный проект.** Не подключать GitHub, Firebase, Cloudflare Workers, D1, почтовые ключи или DNS проектов Velar Dream и Sanastoyhteisö. Не копировать их приватные данные.

- `main` — базовые документы и только одобренные релизы.
- `preview` — тестовый лендинг и дальнейшая разработка.
- Тестовый просмотр GitHub Pages: будет доступен после включения GitHub Pages с ветки `preview`, папки `/ (root)`.
- Будущий `pakkasukko.fi` — отдельная регистрация домена и конфигурация Cloudflare (пока не подтверждены).
- Публикация лендинга **не включает** приём настоящих бронирований.

## Первые требования
- Впечатляющая адаптивная зимняя страница, фото/видео и возможность замены изображений.
- С 1995 года — 31 год опыта выступлений на 2026 год, включая работу в музыкальном театре Республики Карелия и роли Деда Мороза.
- Короткое поздравление от 50 €, домашняя программа от 100 €, корпоративы и дискотеки — по договорённости; поездки за пределы Kitee оплачиваются отдельно.
- Календарь финского времени Europe/Helsinki, заявка без регистрации, **только после ручного подтверждения**.
- Отдельная закрытая админка, управление временем и контентом, сообщения и экспорт CSV.
- Персональные данные хранить только в собственной защищённой базе Pakkasukko с политикой конфиденциальности по GDPR; не в публичном GitHub Pages.

## Статус
RUN-002. Первую версию смотрим отдельно; пока нет D1, защищённого API, anti-spam и подтверждённой доставки email, форма бронирования не должна принимать реальные заявки.

Развитие и история изменений — только в этом репозитории.
