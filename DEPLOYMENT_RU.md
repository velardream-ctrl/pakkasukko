# Pakkasukko — запуск тестовой версии и защищённого бронирования

## Где ведётся работа
- **Только** https://github.com/velardream-ctrl/pakkasukko
- \`main\` — стабильный основной код, не менять без согласования.
- \`preview\` — текущий тестовый прототип, код лендинга в \`docs/\`.
- Не переносить сюда настройки, базы или секреты Velar Dream / Sanastoyhteisö.

## 1. Бесплатный предпросмотр лендинга через GitHub Pages

Владелец один раз открывает:
https://github.com/velardream-ctrl/pakkasukko/settings/pages

Затем:
1. **Build and deployment → Source:** \`Deploy from a branch\`
2. **Branch:** \`preview\`
3. **Folder:** \`/docs\`
4. **Save**.

После публикации ожидаемый адрес:
https://velardream-ctrl.github.io/pakkasukko/

Если Pages ещё не включён, адрес может отвечать 404 до завершения публикации.
В GitHub Pages работают только HTML/CSS/JS; серверные API, календарь реальных заявок и админка требуют Workers + D1. Поэтому на Pages форма намеренно заблокирована. GitHub Pages **не хранит** персональные данные.

## 2. Самостоятельная Cloudflare-база для Pakkasukko

Нельзя использовать D1/Firebase существующих проектов.
В Cloudflare создать новую D1-базу с названием \`pakkasukko-db\`.
Скопировать ID этой **новой** базы в \`wrangler.toml\` вместо нулевого ID.

Локально с Node.js 22+ (либо GitHub Work / подходящий облачный CI с разрешённым доступом Cloudflare):

\`\`\`bash
npm install
npx wrangler login
npx wrangler d1 create pakkasukko-db
# После записи database_id в wrangler.toml:
npm run db:remote
npm run deploy
\`\`\`

При первом запуске не открывать приём заявок: \`ACCEPT_BOOKINGS = "false"\` по умолчанию.
Пока D1 ID равен \`00000000-0000-0000-0000-000000000000\`, deployment не готов.

## 3. Секреты и настройки — только Cloudflare

Никогда не отправлять секреты в чат и не добавлять их в git / README.

\`\`\`bash
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put SESSION_SECRET
npx wrangler secret put TURNSTILE_SECRET
npx wrangler secret put RESEND_API_KEY
\`\`\`

- ADMIN_PASSWORD — отдельный сложный пароль администратора.
- SESSION_SECRET — уникальная случайная строка от 32 символов.
- TURNSTILE_SECRET — секрет **нового** Cloudflare Turnstile виджета Pakkasukko.
- RESEND_API_KEY — ключ почтового сервиса с проверенным отправителем.
- В \`wrangler.toml\` заполнить публичные \`TURNSTILE_SITE_KEY\`, \`OWNER_EMAIL\` и \`FROM_EMAIL\`. Встроенные пустые значения являются заглушками.

Проверить сайт на временном \`*.workers.dev\` домене, загрузку /api/health и /admin.

## 4. Проверки перед приёмом клиентов

1. Указать владельца данных и готовую политику конфиденциальности (GDPR), сроки хранения и способ удаления сведений.
2. Проверить Turnstile, ограничения запросов и вход администратора; включить 2FA в аккаунтах.
3. Проверить запись в D1: добавить слот в /admin → выбрать слот на сайте → отправить тестовую заявку → посмотреть статус pending в админке → подтвердить → убедиться, что второй клиент не может занять тот же слот → экспортировать CSV.
4. Проверить email-уведомления, мобильный iPhone Safari, планшет и компьютеры.
5. Проверить резервное копирование и восстановление отдельной D1.
6. Только после этих шагов изменять \`ACCEPT_BOOKINGS = "true"\` и снова разворачивать Worker.

Отправка заявки **не равна подтверждению**. Дед Мороз проверяет маршрут и расписание перед ручным подтверждением. Переезды необходимо блокировать отдельными слотами.

## Особенности календаря
Время хранится в локальной записи \`YYYY-MM-DDTHH:mm\` Europe/Helsinki.
Вблизи перехода на летнее/зимнее время следует проверять неоднозначные часы отдельно.
Цены указаны от 50 € / от 100 € только для района Китее и могут корректироваться по расстоянию.
