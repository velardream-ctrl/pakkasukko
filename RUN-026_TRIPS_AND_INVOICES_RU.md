# RUN-026 · Несколько адресов, общая поездка и счета

На один день можно выбрать несколько интервалов одной программы в одном городе. Для каждого времени нужен адрес. Каждый визит имеет собственное бронирование, статус и ссылку на расчёт. Все визиты сохраняются одной транзакцией. Стоимость программы начисляется за каждый визит, расходы на общую поездку — один раз.

На дату услуги в подтверждённом заказе нажмите «Зафиксировать выезд». В него войдут ещё не распределённые подтверждённые заказы в тот же город на ту же дату с тем же способом поездки. Отменённые заказы и видеопоздравления исключены. Используется наименьший из зафиксированных тарифов маршрута, доли округляются в центах в порядке визитов. Максимум каждого заказа сохраняется. После выезда доли зафиксированы; последующие подтверждения относятся к следующему выезду.

Реквизиты для счетов и PDF находятся в админке. Укажите адрес, IBAN, ставку ALV и VAT ID либо основание отсутствия налога; при необходимости загрузите свой логотип. Тарифы считаются конечными ценами с учётом применимого налога. Форма рассчитана на одну налоговую ставку для программы и относящихся к ней расходов. Выписанный счёт получает постоянный номер, сохраняет суммы и реквизиты на дату выдачи. Откройте PDF для сохранения или печати или отдельно нажмите «Отправить счёт клиенту» для отправки вложения. Для заказа с индивидуальной ценой укажите согласованную сумму перед выдачей.
