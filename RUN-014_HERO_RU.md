# RUN-014 — Новый первый экран Pakkasukko

**Цель:** убрать излишнюю рамку и неудачное встраивание Деда Мороза в маленький прямоугольник. Оставить владельческий портрет со светящимся посохом главным визуальным акцентом.

- **Компьютер:** Дед Мороз крупно справа в стиле кинопостера; изображение начинается ниже навигации, мягко переходит в ночной фон слева. Текст и кнопки находятся слева, не затемняя лицо или посох. Главный портрет без подложки и рамки (отступы-«открытки» в остальных разделах сохраняются).
- **Планшет и телефон:** фотография над текстом; плавное исчезновение нижнего края в фон; шапка, лицо, светящийся посох видны. Контент остаётся ниже, без перекрытия фото.
- Применяется CSS object-fit:cover с object-position:center top для выразительного кадрирования по пояс; административные координаты X/Y и масштаб работают.
- Не трогаем изображения R2, текст, календарь и другие проекты.
- Базовое затемнение сохраняет редактируемый режим 0–100%, по умолчанию 0%.
- Изменён только `docs/style.css`; проверки `tests/hero-layout.test.js`. Макет проверен локально на размерах 1440×900, 820×1180, 390×844, но требует финальной проверки на реальном сайте владельцем.
