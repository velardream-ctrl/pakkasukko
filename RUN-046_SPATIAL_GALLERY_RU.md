# RUN-046 — Пространственные фотографии на Pakkasukko

## Цель

Встроить ранее согласованную трёхслойную имитацию объёма из тестовой страницы в основной сайт **без публичного переключателя «Фото / 3D»**.

## На сайте

- Для владельца в админке: \`spatial-admin.html\`.
- Для каждого устройства (телефон / планшет / компьютер) — отдельный выбор: обычное фото или пространственная сцена и конкретная сцена.
- По умолчанию остаётся обычная главная фотография. Другие фотографии и их кадрирование не затронуты.
- Режим 3D: вырезанный персонаж, неподвижная земля и движущийся лес/церковь. Переход между двумя фоновыми слоями находится только на снегу около сапог.
- Плавный автопоказ, управление мышью и пальцем. На iPhone можно коснуться самой пространственной фотографии, чтобы разрешить движение датчика; если разрешение отсутствует, управление пальцем остаётся рабочим.
- При ошибке загрузки слоёв основной портрет остаётся доступен.

## Новые пространственные сцены

1. Подготовить PNG/WebP персонажа с прозрачностью **по контуру**.
2. Подготовить широкий JPEG/PNG/WebP зимнего фона **без персонажа**, восстановив скрытую область.
3. Войти в админку → «Пространственные фотографии».
4. Загрузить оба слоя в подключённое R2 (существующая авторизованная загрузка). Третий файл неподвижного снега необязателен; по умолчанию используется тот же широкий фон.
5. Назначить новую сцену для нужных устройств и выбрать «Пространственная», затем опубликовать.

**Ограничение:** сайт не выполняет автоматическую нейросетевую вырезку и дорисовку из одного исходного фото. Такие слои сначала нужно подготовить. Для обычных фотографий сохраняется прежний редактор.

## Безопасность и совместимость

- Доступ на запись — только с существующей сессией владельца.
- В модели публикации хранятся только UUID слоёв, изображения в R2.
- Публичный доступ к загруженным слоям разрешён только когда на них ссылается опубликованная пространственная сцена.
- При выключенном пространственном показе остаются прежняя фотография и прежние настройки кадрирования, без потери данных.
- Не затрагиваются D1 таблицы заказов, календарь, цены и другие проекты.
