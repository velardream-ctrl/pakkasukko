# RUN-009 · Редактирование прямо на сайте Pakkasukko

Рабочая ветка \`preview\` репозитория \`velardream-ctrl/pakkasukko\`.

## Как пользоваться
1. Войдите в Pakkasukko через \`/admin\` (авторизация только в Cloudflare Worker).
2. Откройте главную страницу **на том же домене** \`pakkasukko.velardream.workers.dev\`.
3. После проверки защищённой сессии появится нижняя панель «✎ Редактирование», «Разделы», «＋ Раздел», «Сохранить черновик» и «Опубликовать».
4. Щёлкните ✎ рядом с нужным текстом: справа откроется панель изменения его фрагментов, а изменения будут видны сразу.
5. Щёлкните ▣ на фотографии: выберите снимок из медиатеки или загрузите новый в отдельное R2 \`pakkasukko-preview-media\`, перетаскивайте фото мышью или пальцем, меняйте масштаб и положение X/Y.
6. Для фотографий в секциях координаты независимы для desktop/tablet/phone. Для проверки другого устройства измените ширину окна либо откройте полный визуальный редактор \`/editor\`.
7. Нажмите «Сохранить черновик», затем после проверки — «Опубликовать». Отмена возвращает последний загруженный/сохранённый черновик.
8. Значок ⚙ у каждого раздела открывает меню порядка, скрытия и назначения фотографии; ссылки на расширенный редактор и календарь сохранены.

## Безопасность
- Панель и её JavaScript загружаются на главной странице только если \`/api/admin/editor\` отвечает успешно с сессионным cookie, проверяемым сервером; для обычного посетителя нет иконок и доступ к API запрещён.
- Пароль не хранится в JavaScript. Правки принимаются только защищённым API с проверкой Origin и сессионного cookie.
- Публикация — отдельное подтверждаемое действие. Конфликты версий предотвращает id ревизии.
- В GitHub Pages редактор недоступен: нужна настоящая сессия Cloudflare Worker и D1.
- Приём реальных заявок остаётся выключен.

## Проверки
\`npm test\` + \`node --check docs/inline-editor.js\`.
Проверка на реальном телефоне владельца и загрузка нового фото через админскую сессию должны быть выполнены отдельно.

## Изоляция
Все изменения только в \`pakkasukko/preview\`. Не использовать данные и ресурсы других проектов.
