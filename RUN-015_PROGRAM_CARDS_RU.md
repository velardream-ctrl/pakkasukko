# RUN-015 — Единый дизайн дополнительных программ

**Проблема:** Три исходные программы были вёрсткой HTML с `card-icon`, `card-number`, составным заголовком с `em` и `card-foot`. Новые программы из админки выводились как простой `article.card` с заголовком, абзацем, ценой и ссылкой непосредственно в колонке. Поэтому «Видеопоздравление от Деда Мороза» выглядело совсем иначе.

**Решение:**
- Все программы из `model.cards` используют ту же структуру CSS, что и исходные карточки.
- Иконка, категория и подсвеченный фрагмент заголовка задаются автоматически при отсутствии полей, но владелец может изменить их в полном редакторе или на сайте через карандаш.
- Для текущей четвёртой карточки: `▶`, `04 / ВИДЕОПОЗДРАВЛЕНИЕ`, «Видеопоздравление» + золотое «от Деда Мороза».
- Внешне цена и кнопка находятся в общей нижней полосе, время/длительность — над ней.
- Для четырёх программ на широком экране: аккуратная симметричная сетка 2×2, на мобильном — одна колонка. При пяти и более сетка возвращается к обычным трём колонкам, поэтому правило работает только с четырьмя.
- Дополнительные поля `icon`, `label`, `accent` необязательны, старые записи в D1 не мигрируются и не теряются, описание и стоимость остаются прежними.
- Путь `docs/site.js` остаётся единственным рендерером и для опубликованной страницы, и для предпросмотра редактора.
- Другие репозитории и данные не затрагиваются; изменения только `velardream-ctrl/pakkasukko`, ветка `preview`.

Проверка: `npm test` + отдельные регрессионные тесты `tests/program-cards.test.js`. Живое визуальное тестирование владельцем после публикации.
