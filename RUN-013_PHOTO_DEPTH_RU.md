# RUN-013 — Единый эффект объёмных фотографий

**Решение:** тёплая бежевая подложка справа и снизу — это намеренный дизайнерский эффект, не дублирование фотографии. Применён ко всем основным областям фотографий: первый экран, «Подарить воспоминание», «У волшебства есть голос», арка «Сказка найдёт дорогу» и дополнительные изображения разделов.

- Подложка создаётся только CSS `box-shadow` и **не является второй фотографией**.
- У светлых разделов подложка светло-бежевая, у арки на тёмном фоне — насыщенно-золотистая.
- Основной отступ: 18px, на узком экране: 9px. У главной фотографии эффект спокойнее.
- Сами фотографии не перемещаются; не меняются масштаб/кадрирование пользователя, файлы R2 и тексты.
- Внутреннее изображение остаётся обрезано строго по границе своей рамки/арки.
- Эффект статичный (не анимированный параллакс), чтобы не раздражать на телефонах.

Изменения только в `velardream-ctrl/pakkasukko`, ветка `preview`.
