# RUN-038 — способы оказания услуг

Все исходные и дополнительные карточки имеют явную настройку visit (личный визит с часами) или delivery (получение по дате без часов и поездки). Полный и встроенный редакторы, сохранение в черновик и публикация. Срок подготовки 0–365 дней для обычной услуги, минимум 7 для видеопоздравления; по умолчанию 7 для delivery. Старые карточки видео сохраняют delivery, остальные — прежний режим. Явная настройка имеет приоритет над названием. Форма и сервер используют общий resolver. Заказы по дате в существующей таблице video_orders, отдельный раздел админки; без автоматических счетов и доставки файлов. Существующие заказы не мигрируются. Добавлены тесты.
