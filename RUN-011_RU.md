# RUN-011 — Яркость и затемнение первого экрана

На портрете Деда Мороза нет текста, поэтому по умолчанию наложенное затемнение полностью выключено (0%). Портрет теперь непрозрачен (opacity 1).

Администратор Pakkasukko после входа:
- На сайте: кнопка «▣» на верхнем портрете → «Затемнение фотографии», ползунок 0–100% и «Убрать затемнение (0%)».
- В отдельном редакторе /editor: «Перемещение и масштаб фотографий» → «Главный экран · Дед Мороз» → ползунок затемнения 0–100%.
- Настройки отдельные для desktop/tablet/phone, сохраняются в `model.shades` в черновике D1 и вступают в силу для посетителей после «Опубликовать».
- Выключение наложения по умолчанию применяется и на статической предпросмотровой версии.
- Фотография, костюм, посох, текст и другие проекты не меняются.

Проверки `npm test`; браузерный просмотр остаётся финальным этапом.
